## Migration impact and limitations

No domain tables/migrations yet. Idempotent database bootstrap enables pgvector;
initial domain schema belongs to P0-04. DB bootstrap uses local development
credentials; runtime/admin DB grants are deliberately pending P0-03.

No provider generation requests, official rubric content, student records, or
admin/student operations were introduced. LiteLLM availability does not certify
provider capabilities; those are P0-06. Storage IAM and upload safeguards are
pending later phase 0 tickets. The entire phase 0 security gate is still open.

Five high-severity npm development-tool advisories remain in the
`eslint-config-next → fast-glob → micromatch → braces` chain; the registry's latest
braces release is still 3.0.3 with no patched release. These tools are not part
of the deployed standalone runtime. Avoid processing untrusted glob patterns;
recheck the chain before pilot release. Earlier critical test-runner advisories
were removed by updating Vitest.
